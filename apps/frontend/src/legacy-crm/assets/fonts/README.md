# tw-sung-legacy.woff2

全字庫正宋體（TW-Sung, version 11503.01）的子集：CP950（Big5）字元、ASCII、Latin-1、CJK 標點與全形字元，去除 hinting，轉成 WOFF2。

- 來源：數位發展部「全字庫」 https://www.cns11643.gov.tw/opendata/Fonts_Sung.zip （https://data.gov.tw/dataset/5961）
- 授權：字型名稱表允許擇一使用「政府資料開放授權條款-第一版」或 SIL OFL 1.1；本子集依「政府資料開放授權條款-第一版」（https://data.gov.tw/license）使用。
- 出處標示：(c)2026 數位發展部，全字庫正宋體。

用途：沒有安裝細明體（MingLiU）的電腦上，列印與舊版畫面用它代替細明體。
